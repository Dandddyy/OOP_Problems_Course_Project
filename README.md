# KyivDrive

KyivDrive — мобільний застосунок для спільних автомобільних поїздок у Києві. Водії публікують маршрути й розклад своїх поїздок, а пасажири знаходять варіанти з місцями посадки й висадки поблизу потрібних адрес.

## Можливості

### Для водія

- Перегляд маршруту на мапі зі зміною порядку проміжних точок і вибором зупинок уздовж маршруту.
- Публікація разової або регулярної поїздки за днями тижня. Водій указує час виїзду, фіксовану ціну або тариф за кілометр.
- Додавання автомобілів із зазначенням кількості пасажирських місць і вибір автомобіля для поїздки.

### Для пасажира

- Пошук поїздок на конкретну дату або на вибрані дні тижня. Пасажир може визначити, що важливіше під час пошуку, наприклад час виїзду чи прибуття, вартість або тривалість ходьби.
- Перегляд результатів із вартістю та тривалістю поїздки. У картці результату видно час виходу, посадки, висадки й прибуття до кінцевої адреси.

### Спільні функції

- Пошук адрес із підказками та вибір точки на мапі з визначенням адреси за координатами.
- Збереження, повторне використання та видалення шаблонів маршрутів.
- Профіль користувача й перемикання між режимами водія та пасажира.
- Реєстрація, вхід із паролем або через Google та відновлення пароля за кодом з електронної пошти.

## Склад проєкту

- **Мобільний клієнт** на Flutter для Android та iOS. GoRouter керує навігацією між екранами, Dio — запитами до REST API.
- **Бекенд** на Java 21 і Spring Boot. PostgreSQL зберігає облікові записи, поїздки, автомобілі, зупинки й шаблони. PostGIS виконує просторові запити, а Liquibase керує змінами схеми бази даних.
- **Мапа й геодані.** Mapbox надає підкладку мапи, Geoapify — підказки адрес і зворотне геокодування. OSRM використовує окремі графи OpenStreetMap для автомобільних і пішохідних маршрутів. Бекенд підтримує імпорт каталогу зупинок із попереднім переглядом змін та історією імпортів.
- **Кешування й зовнішні сервіси.** Службовий Redis зберігає одноразові коди та лічильники запитів. Окремий Redis кешує геодані, довідники й дані пошуку поїздок. Brevo надсилає листи для підтвердження адреси й відновлення пароля.

Під час пошуку PostGIS відбирає можливі пари місць посадки й висадки вздовж опублікованих маршрутів. Пішохідний OSRM обчислює час і відстань від адреси пасажира до посадки та від висадки до кінцевої адреси. Бекенд вибирає одну пару для кожної поїздки й ранжує результати за пріоритетами пасажира.

## Розподіл відповідальності

### Андрій Антонов

- **Авторизація** — екрани й API реєстрації та входу з паролем або через Google, надсилання одноразових кодів через Brevo та перевірка кодів для підтвердження електронної пошти й відновлення пароля.
- **Пошук адрес і вибір точки на мапі** — підказки для початкової й кінцевої адрес у `address_search_screen.dart`, вибір точки з визначенням її адреси в `map_selection_screen.dart`, API автодоповнення й зворотного геокодування через Geoapify.
- **Шаблони маршрутів** — збереження адрес і геометрії маршруту, а для водія також проміжних точок і зупинок. Список шаблонів для поточного режиму, відкриття збереженого маршруту на екрані перегляду та API створення, отримання списку й видалення шаблонів.
- **Профіль користувача** — відображення імені, аватара, рейтингу й кількості відгуків, API отримання цих даних та перемикач режимів водія й пасажира.

### Коваленко Данило

- **JWT і сесії** — підпис і перевірка access та refresh JWT, ротація refresh-токенів, автоматичне оновлення токенів у Flutter та API перегляду й завершення сесій на пристроях.
- **Головний екран і маршрути** — мапа з геолокацією, екрани перегляду маршруту для водія та пасажира, редактори проміжних точок і зупинок, серверний розрахунок маршруту через OSRM.
- **Публікація поїздок і автомобілі** — форма та API публікації, перевірка маршруту, розкладу й ціни на бекенді, довідник марок і моделей та API керування автомобілями.
- **Пошук поїздок** — налаштування пріоритетів і екран результатів, просторовий відбір поїздок, підбір місць посадки й висадки, розрахунок піших ділянок, ранжування та посторінкове завантаження результатів.
- **Дані та інфраструктура** — міграції PostgreSQL/PostGIS, імпорт і версіонування каталогу зупинок, підготовка автомобільного й пішохідного графів OSRM, конфігурація службового Redis і Redis для кешу.
